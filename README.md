We will create a simple 'todo list' application using Python. This application will allow users to add, view, modify, and
delete tasks from their todo list. These tasks will be saved and loaded from a csv file named tasks.csv under the data directory. Each task 
will have a priority and date associated with it. We will use a dictionary to store the tasks, where the keys will be the task names 
and the values will be a list containing the priority and date.
